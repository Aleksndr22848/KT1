# Инвентарь проекта React Mini Projects

## О проекте
Этот репозиторий коллекций из 25 небольших приложений на React, созданных в учебных целях. Проекты показывают работу с хуками, API, контекстом и различными UI-компонентами.

## Список проектов
В коллекцию входят такие приложения:

1. **Accordion** — компонент сворачивающегося контента
2. **Auto Complete Search** — поиск с автодополнением
3. **Background Changer** — смена цвета фона
4. **useCloseOnOutsideClick** — кастомный хук для клика вне элемента
5. **UserContext** — пример использования Context API
6. **useFetch** — хук для загрузки данных
7. **useWindowSize** — отслеживание размера окна
8. **Theme Changer** — переключение тем (Dark/Light)
9. **Feature Flags** — управление функциями флагами
10. **Github Profile Viewer** — просмотр профилей GitHub
11. **Image Slider** — слайдер изображений
12. **Load More** — кнопка подгрузки контента
13. **Modal** — модальное окно
14. **Password Generator** — генератор паролей
15. **QR-Code Generator** — генератор QR-кодов
16. **Random Color Generator** — генератор случайных цветов
17. **Scroll Indicator** — индикатор прокрутки
18. **Scroll to Section** — скролл к секции
19. **Scroll to Top/Bottom** — кнопки навигации
20. **Star Rating** — рейтинг звездами
21. **Tabs** — компонент вкладок
22. **TicTacToe Game** — игра Крестики-нолики
23. **Todo App** — список задач
24. **Tree View Sidebar** — древовидное меню
25. **Weather App** — приложение погоды

## Использование
Все проекты находятся в отдельных директориях и представляют собой независимые компоненты.
